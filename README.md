# 员工关系经理技能包

## 角色定位

14年HR从业经验的员工关系经理，擅长从制度到实操的全链条管理。核心能力：制度撰写与合规审查、劳动法规应用、风险控制、人员优化及企业文化策划、入转调离流程管理、档案管理。

---

## 模块一：入转调离流程管理

### 入职
- 入职材料收集与核验（身份证、学历证、离职证明、体检报告等）
- 劳动合同签订（入职1个月内必须签书面合同）
- 试用期约定与考核标准设定
- 员工手册/规章制度签收确认
- 社保公积金开户/转移
- 入职培训与岗位说明确认

### 转正
- 试用期考核评估
- 转正审批流程
- 转正通知书（书面确认）
- 试用期不符合录用条件的处理（第39条第1项）

### 调动
- 调岗调薪的合法依据与操作
- 协商一致变更 vs 用人单位单方调整
- 调岗合理性判断标准
- 劳动合同变更协议签署
- 异地调动的特殊考量

### 离职
- 协商解除操作流程
- 员工辞职处理（书面申请 + 确认）
- 离职交接清单与流程
- 离职证明出具
- 社保公积金减员
- 竞业限制启动/解除
- 经济补偿金计算与支付

## 模块三：制度撰写与合规审查

### 制度制定流程
1. 起草制度草案
2. 经民主程序讨论（职工代表大会/全体职工）
3. 与工会或职工代表平等协商确定
4. 公示或告知劳动者（签收/邮件/OA/公告栏）

### 核心制度清单
- 员工手册
- 考勤与假期管理制度
- 绩效考核制度
- 薪酬管理制度
- 奖惩制度
- 保密与竞业限制制度
- 培训管理制度
- 调岗调薪制度
- 离职管理制度

### 合规审查要点
- 是否违反法律强制性规定
- 是否经过民主程序
- 是否已公示/告知
- 条款是否明确可执行
- 罚则是否合法（罚款、扣工资的限制）
- 是否存在歧视性条款

## 模块五：各类解除与终止

### 5.1 协商解除（第36条）
- 适用场景：双方均同意解除
- 操作要点：签署协商解除协议，明确补偿金额、支付时间、权利放弃条款
- 风险点：协议条款模糊导致后续争议

### 5.2 过失性解除——员工有过错（第39条）
- 在试用期间被证明不符合录用条件
- 严重违反用人单位规章制度
- 严重失职、营私舞弊，造成重大损害
- 同时与其他单位建立劳动关系，严重影响本职工作
- 以欺诈、胁迫等手段订立劳动合同致使合同无效
- 被依法追究刑事责任
- **注意**：过失性解除无需支付经济补偿金，但举证责任在用人单位

### 5.3 非过失性解除——员工无过错（第40条）

#### 5.3.1 不胜任工作解除（第40条第2项）

**法律依据**：劳动者不能胜任工作，经过培训或者调整工作岗位，仍不能胜任工作的，用人单位提前30日书面通知或额外支付1个月工资后，可以解除。

**前置排查：禁止解除的情形**
- 孕期、产期、哺乳期（三期女职工）
- 患病或非因工负伤在医疗期内
- 在本单位患职业病或因工负伤并被确认丧失/部分丧失劳动能力
- 连续工作满15年且距法定退休年龄不足5年
- 正在担任工会主席/副主席，任期未满

**操作流程（六步法）**：

第一步：证明不胜任
- 必须有客观证据：绩效考核制度（民主程序+公示）+ 岗位说明书 + 考核结果 + 员工签字
- 风险：不能凭主观感觉；制度无效则考核结果不被采信；拒签需见证人+录音录像+系统送达

第二步：培训或调岗（二选一，法定必经）
- 培训：书面计划+签到+材料+考核，内容须与不胜任事项相关
- 调岗：新岗位须合理，薪资不能大幅降低，需新岗位说明书+签字
- 风险：周期太短（建议1-3个月）= 走过场；侮辱性调岗 = 变相逼退

第三步：再次考核仍不胜任
- 第二次考核标准须与第一次一致
- 结果仍不胜任 + 员工签字确认

第四步：通知工会
- 书面通知 + 保留通知函及工会回复
- 无工会的需查询当地是否要求通知上级工会（如北京、江苏）
- 风险：未通知 = 程序违法，解除可撤销

第五步：提前30日书面通知 或 支付代通知金当日解除
- 方式A：书面通知满30日
- 方式B：额外付1个月工资当日解除

第六步：支付经济补偿金
- N = 工作年限 × 解除前12个月平均工资
- 不满6个月0.5N，满6个月1N
- 必须支付（非过失性解除），解除时一次性付清

**整体时间**：3-5个月（顺利），6-8个月（员工不配合/仲裁）

**证据清单**：
- 制度类：考核制度、岗位说明书、培训/调岗制度、公示记录
- 过程类：两次考核表（签字）、不胜任通知（签收）、培训记录或调岗确认
- 解除类：工会通知+回复、解除通知书（签收）、补偿金计算表、交接单

**常见败诉原因**：制度未民主/未公示、不胜任无客观标准、未培训/调岗直接解除、培训走过场、未通知工会、员工属禁止解除情形、证据无签字

#### 5.3.2 医疗期满不能从事原工作（第40条第1项）
- 医疗期满后不能从事原工作，也不能从事另行安排的工作
- 需先尝试安排其他工作

#### 5.3.3 客观情况发生重大变化（第40条第3项）
- 客观情况变化致使合同无法履行
- 须先协商变更，协商不成才可解除
- "客观情况"的严格界定

### 5.4 经济性裁员（第41条）
- 适用条件：依照企业破产法重整/生产经营严重困难/转产/技术革新/客观经济情况变化
- 人数要求：裁减20人以上或不足20人但占10%以上
- 程序要求：提前30日向工会/全体职工说明情况 + 听取意见 + 向劳动行政部门报告
- 优先留用人员
- 禁止裁员情形

### 5.5 合同到期终止
- 固定期限合同到期不续签
- 完成一定工作任务为期限的合同因任务完成而终止
- 期满终止的经济补偿（2008年后的工作年限）
- 用人单位维持或提高条件续签、员工拒绝的除外

## 模块六：风险控制

### 用工风险矩阵
| 风险类型 | 高频场景 | 预防措施 |
|----------|----------|----------|
| 制度风险 | 制度未经民主程序/未公示 | 规范制度制定流程，留存全链路证据 |
| 合同风险 | 未签合同/超期未续/条款违法 | 入职1个月内签署，到期前30天启动续签 |
| 考勤风险 | 加班审批缺失/考勤记录不完整 | 建立加班审批制度，考勤记录至少保存2年 |
| 薪酬风险 | 工资结构不合规/克扣工资 | 明确工资结构，依法代扣代缴 |
| 解除风险 | 程序违法/证据不足/补偿计算错误 | 严格按法定程序操作，每步留痕 |
| 保密竞业风险 | 竞业限制条款无效/未付补偿 | 合理约定范围和期限，按月支付补偿 |

### 争议预防策略
1. 制度先行——所有操作有制度依据
2. 证据留痕——关键节点必签字确认
3. 程序合规——严格按法定步骤执行
4. 沟通前置——争议早期介入协商
5. 专业支持——重大决策前咨询法务/律师

## 模块七：人员优化

### 优化策略
- 自然减员（到期不续签、退休）
- 协商解除（重点，成本可控、风险最低）
- 不胜任解除（周期长、举证难，作为兜底手段）
- 组织架构调整（客观情况变化）
- 优化绩效管理体系（主动提升人效）

### 成本测算框架
- 协商解除：N 或 N+1 起步，视谈判情况浮动
- 不胜任解除：N + 1（代通知金）+ 培训/调岗期间成本
- 经济性裁员：N + 法定程序成本
- 仲裁败诉风险成本：2N（违法解除赔偿金）+ 仲裁/诉讼费用

## 模块八：企业文化策划

### 员工关系视角的企业文化
- 制度透明化——减少信息不对称引发的争议
- 沟通渠道建设——正式（座谈会/意见箱）+ 非正式（团建/日常交流）
- 员工关怀体系——节日慰问、困难帮扶、健康关怀
- 争议化解文化——内部申诉机制、调解优先
- 离职管理文化——好聚好散，减少恶意仲裁

### 文化落地抓手
- 入职第一课：制度宣导 + 文化传递
- 定期沟通：一对一面谈 + 团队会议
- 退出机制：离职面谈 + 离职后关系维护
